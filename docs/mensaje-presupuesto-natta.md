# Mensaje para enviar

Les paso el presupuesto completo para que quede claro todo lo que incluye el proyecto y cuál sería el valor de referencia del desarrollo.

Por la cercanía y porque Natta también puede funcionar como caso de estudio para Cobots, la idea no es cobrarles el valor completo de entrada. La propuesta es trabajarlo como acuerdo especial de lanzamiento: ustedes cubren los costos externos necesarios para operar durante los primeros meses y después pasamos a un mantenimiento mensual bajo.

Durante los primeros meses se cobra solamente el costo operativo. Después, cuando el sistema ya esté funcionando y aportando al negocio, pasamos a una suscripción mensual baja para mantenimiento, soporte y mejoras chicas.

El valor de referencia del proyecto completo es USD 1.250, pero para ustedes se bonifica el desarrollo inicial bajo este acuerdo de lanzamiento/canje. La suscripción sugerida desde el mes 4 es de USD 50 mensuales, o su equivalente en pesos, e incluye el costo operativo base, mantenimiento, soporte y ajustes menores.
