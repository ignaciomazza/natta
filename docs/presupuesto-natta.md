# Presupuesto - Web y sistema de pedidos para Natta

Fecha: 7 de mayo de 2026

Cliente: Natta

Proveedor: Cobots

## 1. Objetivo del proyecto

Desarrollar una plataforma digital para Natta que ordene la venta por encargo, mejore la experiencia del cliente y prepare el negocio para operar con mayor volumen sin depender solamente de mensajes manuales.

El proyecto incluye una web comercial, catálogo de productos, flujo de armado de pedido, reglas de disponibilidad, integración de pagos, base de datos, panel interno de gestión y mantenimiento posterior.

## 2. Alcance funcional

### Web comercial

- Home institucional con identidad visual de Natta.
- Secciones de historia, producto, menú, preguntas frecuentes y llamados a pedido.
- Diseño responsive para celular, tablet y escritorio.
- Uso de fotos reales de producto y contenido de Instagram.
- Copy y estructura orientados a conversión: que el cliente entienda qué vende Natta, cómo se pide y cuáles son las reglas.

### Catálogo digital

- Sabores, tamaños, descripciones y precios.
- Diferenciación por tamaños: Latta, Chica y Grande.
- Reglas de productos: disponibilidad, notas internas y productos activos/inactivos.
- Preparado para actualizar precios y menú desde el sistema.

### Pedido asistido

- Selección de sabores, tamaños y cantidades.
- Calendario con anticipación mínima.
- Bloqueo de domingos y fechas no disponibles.
- Modalidad de retiro o envío.
- Datos del cliente: nombre, teléfono, dirección y notas.
- Cálculo automático de total.
- Cálculo de seña para retiro y pago completo para envío.
- Confirmación del pedido y mensaje ordenado para seguimiento.

### Sistema interno

- Base de datos para catálogo, precios, reglas de disponibilidad y capacidad.
- Registro de pedidos.
- Estados de pedido: pendiente, confirmado, en preparación, listo, entregado, cancelado.
- Panel de administración para Cami y Martín.
- Gestión de cupos diarios y fechas cerradas.
- Notas internas por pedido.
- Búsqueda y filtros por fecha, cliente, estado y modalidad.

### Pagos online

- Integración con pasarela de pago.
- Para retiro: pago de seña del 50%.
- Para envío: pago total del producto.
- El costo de envío queda fuera del checkout y se coordina aparte, según la operatoria actual de Natta.
- Registro del estado de pago en el sistema.

### Automatizaciones y comunicación

- Confirmación de pedido.
- Mensajes de seguimiento por WhatsApp o canal acordado.
- Recordatorios operativos para pedidos próximos.
- Textos base para respuestas frecuentes.

### Publicación y medición

- Deploy de la web.
- Configuración de dominio.
- Variables de entorno y configuración productiva.
- Analítica básica para medir visitas, conversiones y pedidos iniciados.
- QA responsive y corrección de errores antes de publicar.

## 4. Resumen económico

Valor de referencia del proyecto completo: USD 1.250

Este valor es un precio especial pensado para Natta, por la cercanía con el proyecto y por el potencial de usar el caso como parte de la comunicación de Cobots. No representa una tarifa estándar de mercado para un sistema de estas características.

## 5. Acuerdo especial de lanzamiento

Durante el lanzamiento, el proyecto se trabajará bajo un acuerdo mixto de costo + canje.

### Bonificación aplicada

- Desarrollo inicial bonificado por vínculo cercano y acuerdo especial de lanzamiento.
- Natta cubre solamente los costos externos necesarios para operar durante los primeros meses.
- Cobots puede usar el proyecto como caso de estudio público.
- La comunicación pública del caso se coordina aparte entre Natta y Cobots.

### Costos externos a cargo de Natta

- Dominio, si corresponde.
- Hosting, base de datos o servicios cloud, si superan planes gratuitos.
- Comisiones de la pasarela de pago.
- Herramientas externas de WhatsApp, email, SMS o automatización, si se contratan.
- Producción de fotos, videos o contenido profesional, si se decide hacer aparte.

## 6. Mantenimiento posterior

Durante los primeros 3 meses posteriores al lanzamiento, Natta paga solamente los costos externos de operación. El soporte de estabilización queda incluido dentro del acuerdo de lanzamiento.

A partir del mes 4, se propone una suscripción mensual para mantenimiento, soporte y mejoras menores.

### Plan Natta Launch

Suscripción mensual: USD 50 por mes

Incluye:

- Costo operativo base del sistema dentro del mantenimiento mensual.
- Supervisión técnica básica.
- Monitoreo de errores.
- Backups y cuidado general del sistema.
- Ajustes menores de textos, precios, sabores y contenido.
- Soporte operativo por WhatsApp o canal acordado.
- Hasta 2 horas mensuales de mejoras chicas o ajustes.
- Revisión mensual de funcionamiento general.

No incluye:

- Nuevas funcionalidades grandes.
- Rediseños completos.
- Integraciones nuevas no contempladas.
- Producción de contenido audiovisual.
- Campañas pagas de publicidad.
- Comisiones variables de terceros, como pasarela de pago o herramientas externas no contempladas.

Las horas no utilizadas no son acumulables. Las tareas que excedan el plan mensual se cotizan aparte antes de realizarlas.

## 7. Condiciones generales

- Los valores están expresados en dólares estadounidenses como referencia para mantener estabilidad. La facturación o pago puede hacerse en pesos argentinos al tipo de cambio acordado al momento de pago.
- El presupuesto tiene una validez de 15 días.
- Los tiempos de entrega dependen de la entrega de contenido, fotos, textos, datos reales de productos y definiciones operativas.
- Cambios menores están incluidos dentro de cada etapa.
- Cambios de alcance o funcionalidades nuevas se presupuestan por separado.
- La publicación final requiere tener definidos dominio, WhatsApp real, políticas de pago y operatoria de entrega.
