`Instagram_files/` contains original product and brand photos kept as source
assets. The landing should use the compressed copies generated in
`optimized/instagram/`.

`transparent-images/` contains original hero cutouts kept as source assets.
The hero should use the compressed WebP copies generated in
`optimized/hero-pieces/`.

Run `npm run assets:optimize` after replacing source JPG/PNG files. The script
regenerates static optimized assets without using `next/image` or Vercel Image
Optimization.

`menu/` contains original menu photos. The app should use
`menu/optimized/`, which is regenerated by `npm run assets:optimize` as
card-ready 9:10 JPG crops with light per-flavor color grading.

Placeholder product images generated from `scripts/generate-placeholder-assets.mjs`
are still kept as fallback assets.
